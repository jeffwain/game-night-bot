Update collection

The Games tab is built from one file, data/games.json, rebuilt from scratch every time you update. Two sources can feed it and they answer different questions, so the usual answer is both: BoardGameGeek first, then Geekgroup over the top.

1 Sync from BoardGameGeek

The primary source, and the only one with box art and per-person statuses — who owns what, who previously owned it, who has it on a wishlist or wants to play it. Every status on this list is what the filter chips on the Games tab filter by. It pulls each linked player's collection directly, with no browser session involved.

Needs BGG_APP_TOKEN in data/.env (register at boardgamegeek.com/applications) and at least one player linked to a BGG account on the Players tab. The token never comes back to this page. Rebuild re-parses the last sync already saved under data/bgg-raw/ — the thing to press after linking a new player, since that changes whose ratings count.

2 Supplement from Geekgroup Optional

Geekgroup knows four things BoardGameGeek's collection API will not tell us without a request per twenty games: weight, the community's best and recommended player counts, estimated value, and your group's own group rating. Supplementing fills those gaps and refreshes the group rating. It never touches ownership, statuses or box art — the Geekgroup dump covers everyone in the group, including people who are not in this Discord.

On geekgroup.app, open your group's collection with the browser's network tab recording. Right-click the collection.json request → Copy → Copy as cURL, and paste the whole thing here. Then press Test.

It has to be the whole request, not just the URL: this is an undocumented POST whose JSON body carries the group and filters, and whose sign-in rides on session cookies. Ask for it without those and the API answers 200 with a large public group instead of an error — so the sync checks the page count and stops rather than quietly pulling ten thousand strangers' games.

Sync from Geekgroup replaces the whole library with the Geekgroup crawl — the right call only when Geekgroup is your only source, since it has no box art. To keep a BGG sync and fill its gaps, use a saved dump below instead.

3 Or work from a saved dump

No session to capture, and the same two choices. Save the collection.json response from the network tab (one page, or an array of pages) or download the group's CSV export, then Upload it here — or copy it into data/bgg-import/ on the host.

Supplement keeps the library you have and fills in only the four fields above — the normal choice after a BGG sync. Replace library throws the current library away and rebuilds it from this file alone. A CSV export carries weight and player counts for everything, but no per-person owners or ratings, so replacing with one costs you the Owned by column.

Log plays to BoardGameGeek

Used after a host check-in to log what you played, with everyone who was in. The password is BGG_PASSWORD in data/.env — it never lives in the database or on this page.
